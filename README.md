# כתוביות מהירות

אפליקציה לטלפון (אנדרואיד, כרום) לכתוביות בעברית וחיתוכים קטנים. הכול רץ בתוך הטלפון: בלי שרת, בלי חשבון ובלי תשלום. הסרטון לא יוצא מהמכשיר.

## מה היא עושה

1. בוחרים סרטון מהגלריה או מהמצלמה.
2. האפליקציה מתמללת בעברית, עם פיסוק וזמן לכל מילה.
3. מתקנים שורה בנגיעה, חותכים קטע בנגיעה, וגוררים את הקצוות.
4. שומרים סרטון עם כתוביות צרובות: לבן עם מסגרת כהה, כמו בקולנוע.

המילים שהדגם לא בטוח בהן מסומנות. תיקון שביקשת לזכור נשמר במילון ומוחל לבד על הסרטון הבא.

## הקבצים

| קובץ | מה יש בו |
| --- | --- |
| `index.html`, `app.css`, `app.js` | המסכים והזרימה (סגנון "חדר עריכה") |
| `asr.js`, `asr-worker.js` | התמלול: חישוב מאפייני הקול והרצת הדגם |
| `captions.js` | חלוקה לשורות, מילון, חיתוכים, וציור הכתובית |
| `media.js` | הוצאת הקול, תמונות קטנות, וצריבת הסרטון |
| `store.js` | שמירה במכשיר: סרטונים אחרונים ומילון |
| `sw.js`, `manifest.webmanifest` | עבודה בלי קליטה והוספה למסך הבית |
| `models/` | דגם התמלול (72 מגה) |
| `vendor/`, `fonts/` | ספריות ופונטים, כולם מקומיים |
| `blueprint.html` | דף המבנה שאושר לפני הבנייה. נשאר רק במחשב, לא עולה לאוויר |

## איפה היא באוויר

הכתובת: **https://namber14.github.io/ktuviot/** (גיטהאב, כמו "איזון"). מעדכנים כך: משנים קבצים בתיקייה, שומרים נקודת שמירה ודוחפים (`git push`). האתר מתעדכן לבד תוך דקה.

בטלפון: פותחים את הכתובת בכרום, שלוש הנקודות, "התקנת האפליקציה". מאותו רגע היא נפתחת כמו אפליקציה, גם בלי קליטה.

## הרצה במחשב לבדיקה

```
cd "כתוביות-מהירות"
python3 -m http.server 8765 --bind 127.0.0.1
```

ואז לפתוח `http://127.0.0.1:8765/` בכרום. בטלפון האפליקציה חייבת כתובת מאובטחת (https).

## דגם התמלול

`ivrit-ai/zipformer2-66m-streaming-he`, קובצי `sherpa-onnx/*.int8.onnx` ו-`tokens.txt`, מתוך
`https://huggingface.co/ivrit-ai/zipformer2-66m-streaming-he`. פותח על ידי יעקב קולני, רישיון CC-BY 4.0.
אם התיקייה `models/` חסרה, מורידים לשם את ארבעת הקבצים: `encoder.int8.onnx`, `decoder.int8.onnx`, `joiner.int8.onnx`, `tokens.txt`.
